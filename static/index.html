Tokenization

Your message is wrapped in the chat template, then split into sub-word tokens. Each token gets an id.
Are these numbers real?

Yes. Each token runs on the GPU (Apple MPS, float32) with PyTorch forward hooks on every sub-operation. The hooks keep the exact tensors the GPU produced and time each kernel with a GPU sync before and after. The browser replays that recording on a scaled clock.

Matrices show a 128×128 grid of the actual weights. Vectors show every value (long ones are max-pooled to fit the strip). The 🔬 view fetches a full real weight row and redoes the dot product in float64, then checks it against the GPU's answer.

Before recording, the prompt runs once untimed so kernel compilation does not distort the timings. Caveats: syncing after every op makes it slower than normal generation (see the uninstrumented speed at the top). The GPU runs each matmul as thousands of parallel threads; the left-to-right sweep is an ordering for humans. Inside the attention kernel only the softmax weights and the result are captured.
